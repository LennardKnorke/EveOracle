Frontend: React + TypeScript + Vite
UI/UX: Tailwind CSS + shadcn/ui
Architecture Editor: React Flow (for the node-based canvas)
Forms: React Hook Form (for dynamic layer property panels)
State Management: Zustand (to manage the complex state of the graph editor)
API Client: TanStack Query

Backend: FastAPI
Real-time Updates: WebSockets (for streaming training metrics)
Background Tasks: Celery (for handling long-running model training jobs)
