# EveOracle

''Work in Progress. A random idea turned into a project to learn more about React.''

The core concept is to create my own intel interface for the MMORPG EveOnline. Fetches Zkill, ESI statistics and condenses them in one window to provide.
Seperates names and entities whether they belong to the same alliance. Later an interface will be added to train models on past data and integrate the model into the interface for small pvp combat predictions
